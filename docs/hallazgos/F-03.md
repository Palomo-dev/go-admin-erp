# F-03 — Fallback de branch en fn_create_journal_entry

**Severidad:** Alta
**Estado:** Corregido
**Fase:** Fase 0

## Qué es

`fn_create_journal_entry` usaba `MIN(branches.id)` como fallback cuando
`p_branch_id` era null o inválido. Eso asignaba una sucursal arbitraria
al asiento, sin relación con la organización.

## Causa raíz

El fallback no consideraba la organización ni la sucursal principal.

## Acción tomada

Corregido: el fallback ahora usa la sucursal `is_main=true` activa de la
organización. Si no hay sucursal principal, cae a `MIN(id)` dentro de la
organización.

- Migración: `supabase/migrations/20260910130000_f03_fix_fn_create_journal_entry_branch_fallback.sql`
- Rollback: `supabase/rollbacks/20260910130000_f03_fix_fn_create_journal_entry_branch_fallback_rollback.sql`

## Qué falta

Nada. Cerrado.

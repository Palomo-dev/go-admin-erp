# F-11 — Funciones SECURITY DEFINER expuestas a anon

**Severidad:** Alta
**Estado:** Parcial (103 triggers revocados, 223 pendientes)
**Fase:** Fase 1

## Qué es

326 funciones `SECURITY DEFINER` estaban expuestas a `anon` vía
`/rest/v1/rpc/`. Cualquiera podía llamarlas sin autenticación.

## Acción tomada

- 103 funciones de trigger revocadas (`REVOKE FROM PUBLIC`). Ninguna se
  llama como RPC desde el cliente (verificado con grep).
- Resultado: 326 → 223 funciones expuestas a anon (-103).
- Migración: `supabase/migrations/20260910170000_f11_revoke_trigger_functions_from_public.sql`

## Qué falta

- 223 funciones no-trigger siguen expuestas. Necesitan análisis
  individual: agregar validación interna de `organization_id` antes de
  revocar. Fase 2.
- Ver F-11b: 433 funciones tienen `search_path` mutable.

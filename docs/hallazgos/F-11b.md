# F-11b — search_path mutable en funciones

**Severidad:** Media
**Estado:** Pendiente (252 sin tocar)
**Fase:** Fase 1

## Qué es

433 funciones tienen `search_path` mutable, lo que permite ataques de
secuestro de búsqueda si un esquema malicioso aparece primero en el path.

## Acción tomada

Ninguna todavía. Identificadas.

## Qué falta

- Agregar `SET search_path = public, pg_temp` a las 433 funciones.
- El conteo exacto pendiente (252) necesita reconciliación con el
  estado actual de la base antes de documentar más.

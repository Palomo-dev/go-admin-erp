# F-13 — 62 FK de finanzas sin índice

**Severidad:** Media
**Estado:** Documentado
**Fase:** Fase 3b

## Qué es

62 foreign keys en tablas de finanzas no tienen índice en la columna
referenciada. Cada JOIN o WHERE sobre esas columnas hace un seq scan.

## Evidencia

Las del camino crítico:

| Tabla | Columna(s) sin índice |
|---|---|
| `journal_lines` | `(organization_id, account_code)` |
| `journal_entries` | `(organization_id, entry_date)` |
| `invoice_purchase` | `(organization_id, supplier_id, branch_id)` |
| `bank_transactions` | `(bank_account_id, organization_id, trans_date)` |
| `bank_accounts` | `(organization_id, branch_id)` |
| `payments` | `(source, source_id)`, `(payment_date)` |
| `cash_movements` | `(cash_session_id, organization_id)` |
| `accounts_payable` | `(invoice_id)`, `(due_date, status)` |

`invoice_purchase` y `bank_accounts` solo tienen PK — ningún índice
secundario.

## Causa raíz

Las FK se crearon sin `CREATE INDEX` acompañante. Postgres no crea
índices automáticos para FK (a diferencia de MySQL).

## Arreglo

`CREATE INDEX CONCURRENTLY` para cada FK listada. No bloquea
escrituras.

## Qué falta

1. Generar los 62 `CREATE INDEX CONCURRENTLY`.
2. Aplicar vía MCP.
3. Verificar con `EXPLAIN` que los queries usan los índices nuevos.

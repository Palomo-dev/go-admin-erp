# F-15 — Índices duplicados

**Severidad:** Baja (limpieza)
**Estado:** Documentado
**Fase:** Fase 3b

## Qué es

Índices duplicados que ocupan espacio y ralentizan escrituras sin
aportar nada.

## Evidencia

| Tabla | Índice duplicado | Índice idéntico |
|---|---|---|
| `accounts_receivable` | `idx_accounts_receivable_customer` | `idx_accounts_receivable_customer_id` |
| `electronic_invoicing_jobs` | `idx_ei_jobs_org` | `idx_electronic_invoicing_jobs_org` |
| `electronic_invoicing_jobs` | `idx_ei_jobs_status` | `idx_electronic_invoicing_jobs_status` |

Tres pares de índices idénticos. Cada par hace el mismo trabajo.

## Arreglo

`DROP INDEX CONCURRENTLY` para los tres duplicados. Sin riesgo — el
otro índice del par sigue cubriendo las queries.

## Qué falta

1. `DROP INDEX CONCURRENTLY` para los 3 índices redundantes.
2. Aplicar vía MCP.
3. Verificar que no haya degradación de queries con `EXPLAIN`.

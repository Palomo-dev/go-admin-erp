# F-23 — Tablas sin paginación en servidor ni ordenamiento por columna

**Severidad:** Media (deuda técnica)
**Estado:** Documentado
**Fase:** Fase 3c (deuda)

## Qué es

Las tablas de datos del módulo finanzas (y otros) cargan todos los
registros de una sola vez y los ordenan en el cliente. No hay
paginación en servidor ni ordenamiento por columna.

## Evidencia

Patrón repetido en múltiples componentes:
```ts
const { data, error } = await supabase.from('...').select('*')
  .eq('organization_id', orgId);
// Sin .range() para paginar
// Sin .order() en la BD
```

En organizaciones con miles de facturas, esto descarga todo al
navegador.

## Causa raíz

Prototipado rápido: traer todo es más fácil que paginar.

## Arreglo

1. Implementar paginación en servidor con `.range()`.
2. Ordenamiento por columna con `.order()`.
3. Componente reutilizable de tabla paginada.

## Qué falta

No bloquea lanzamiento pero degrada rendimiento con volumen.

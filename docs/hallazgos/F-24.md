# F-24 — Reportes contables sin estado de error

**Severidad:** Media (deuda técnica)
**Estado:** Documentado
**Fase:** Fase 3c (deuda)

## Qué es

Los reportes contables atrapan errores con `catch → console.error`
sin mostrar un estado de error al usuario. El reporte aparece vacío
o en ceros sin explicación.

## Evidencia

Patrón en `ReportesContablesService.ts` y `reportesFinancierosService.ts`:
```ts
} catch (error) {
  console.error('Error al generar reporte:', error);
  return []; // o return 0
}
```

El usuario no sabe si el reporte está vacío porque no hay datos o
porque hubo un error.

## Causa raíz

Prototipado rápido: `console.error` es más fácil que manejar estado
de error en la UI.

## Arreglo

1. Propagar el error al componente.
2. Mostrar un estado de error visible (no un falso vacío).
3. Diferenciar "sin datos" de "error al consultar".

## Qué falta

No bloquea lanzamiento pero dificulta diagnóstico en producción.

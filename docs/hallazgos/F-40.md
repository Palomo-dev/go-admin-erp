# F-40 — ImportLeadsCsv inserta columna GENERADA y no setea customer_type

**Severidad:** Media
**Estado:** Documentado
**Fase:** Fase 2

## Qué es

`src/components/crm/oportunidades/ImportLeadsCsv.tsx:276` inserta `full_name`
directamente en `customers`, pero `full_name` es `GENERATED ALWAYS` en la
tabla. Además no setea `customer_type`, `first_name` ni `last_name`.

## Evidencia

### La columna es GENERATED ALWAYS

```sql
full_name IS GENERATED ALWAYS AS (
  CASE
    WHEN customer_type = 'company' THEN COALESCE(company_name, trade_name, ...)
    ELSE NULLIF(TRIM(first_name || ' ' || last_name), '')
  END
)
```

Insertar en una columna `GENERATED ALWAYS` sin `OVERRIDING SYSTEM VALUE`
debe fallar con error. Si no falla (por configuración de Postgres), el
cliente queda con `full_name = NULL` porque `first_name` y `last_name` no
se setean.

### El insert problemático

`src/components/crm/oportunidades/ImportLeadsCsv.tsx:276`:
```ts
.from('customers')
.insert({
  organization_id: orgId,
  full_name: row.name,  // ← GENERATED, debe fallar
  email: row.email || null,
  phone: row.phone || null,
  company_name: row.company || null,
  metadata: { recordType: 'lead', source: row.source },
})
```

Faltan: `customer_type`, `first_name`, `last_name`.

### Contraste con el import de clientes

`src/components/clientes/ClientesActions.tsx:419` sí lo hace bien:
```ts
const customerData: any = {
  organization_id: orgId,
  customer_type: customerType,
  first_name: isCompany ? (row.companyName || '') : (row.firstName || ''),
  last_name: isCompany ? '' : (row.lastName || ''),
  // NO inserta full_name — es GENERATED
  ...
};
```

## Causa raíz

El import de leads se escribió antes de que `full_name` fuera GENERATED,
o se copió de un patrón que no respetaba la restricción. El import de
clientes (ClientesActions) sí respeta la restricción.

## Arreglo

Reemplazar el insert de ImportLeadsCsv por el patrón de ClientesActions:
- Setear `customer_type` (probablemente `'person'` para leads).
- Setear `first_name` y `last_name` (parsear `row.name`).
- NO insertar `full_name`.
- Mantener `metadata.recordType = 'lead'`.

## Impacto

Los leads importados por CSV probablemente están fallando silenciosamente
(los errores se atrapan en try/catch y solo se cuentan como `failed`) o
creando clientes con `full_name = NULL`. Verificar cuántos customers con
`full_name IS NULL` existen y si coinciden con metadata.recordType='lead'.

# F-44 · Bug de copiar-pegar en fn_recalc_invoice_totals (rama de compras)

**Severidad:** Media (facturas de compra no recalculan totales)
**Estado:** Registrado, no arreglado
**Bloque:** D (antes del cierre de mes)

## Hallazgo

En `fn_recalc_invoice_totals`, la rama no-DELETE tiene un bug de copiar-pegar:

```sql
v_sales_id := COALESCE(NEW.invoice_sales_id,
  CASE WHEN NEW.invoice_type = 'sale' THEN NEW.invoice_id END);

v_purchase_id := COALESCE(NEW.invoice_purchase_id,
  CASE WHEN NEW.invoice_type = 'purchase' THEN OLD.invoice_id END);
                                                                ^^^ OLD, no NEW
```

Ventas usa `NEW`; compras usa `OLD`. En un INSERT, `OLD` es NULL, así que un
ítem de compra con `invoice_type='purchase'` e `invoice_purchase_id NULL`
nunca recalcula totales de la factura de compra.

## Arreglo

Cambiar `OLD.invoice_id` por `NEW.invoice_id` en la línea de
`v_purchase_id`. Arreglo aparte, con su rollback. No se hace ahora — se
registra para el Bloque D.

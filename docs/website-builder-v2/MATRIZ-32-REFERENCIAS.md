## Cómo completar la cobertura

Cada referencia tendrá una ficha de F00 con rutas observadas y patrones reutilizables; no una colección de capturas sin decisión técnica. Por patrón registrar: fuente/ruta, diferencia frente a los existentes, contenido, acción, variante responsive, componente propuesto y fase. Si dos plantillas comparten la misma forma, vincular ambas a una implementación.

Al terminar cada fase añadir archivo real, versión del contrato, escena de preview, evidencia de escritorio/móvil y prueba de la acción. Para formularios indicar si es solicitud, disponibilidad o confirmación; para módulos comerciales indicar la capacidad operativa requerida.

La extracción se refiere a estructura, interacción y lenguaje visual. Fotografías, videos, ilustraciones, fuentes y contenido inicial se producen o licencian mediante F06. Los recursos del cliente son reemplazables y no se mezclan con el catálogo compartido del sistema.

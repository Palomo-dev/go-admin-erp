# GoAdmin ERP — Metadatos para Stores

Este directorio contiene los metadatos, descripciones y configuración necesaria
para publicar GoAdmin ERP en Google Play y App Store.

## Estructura

```
mobile/store/
├── README.md                  — Esta guía
├── google-play/
│   ├── description.txt        — Descripción larga (es-ES)
│   ├── short-description.txt  — Descripción corta (80 chars)
│   ├── data-safety.md         — Data Safety section
│   └── screenshots-guide.md   — Guía de screenshots
├── app-store/
│   ├── description.txt        — Descripción para App Store
│   ├── privacy-questions.md   — Respuestas a App Privacy
│   └── screenshots-guide.md   — Guía de screenshots
└── signing/
    ├── android-keystore.md    — Guía generación keystore
    └── ios-certificates.md    — Guía certificados iOS
```
